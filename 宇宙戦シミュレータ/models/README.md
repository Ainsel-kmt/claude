# 艦のモデル

## いま入っているモデル

両陣営のグランドデザイン（`デザイン.md`。人類統合機構は「軍艦＋幽子の輪」、ザイレンは「線と体節」）にそって作った13艦種の GLB が入っていて、3Dビューアはこれを使います。

| ファイル | 中身 |
|---|---|
| `デザイン.md` | グランドデザイン（形の言葉・色・材質・共通部品・艦種ごとの見分け方・新しい艦種の足し方） |
| `designs.js` | モデルを組み立てるコード（両陣営の共通部品と13艦種） |
| `gallery.html` | 見本のページ。全艦を並べて見る・1隻ずつ回して見る・GLB を書き出す（ブラウザで開く。three.js をネットから読む） |
| `*.glb` | 書き出したモデル（node, guard, comms, quiet, picket, artillery, missile, carrier, base, narm, garmes, elda, flagship）。Blender などほかの道具でも開ける |
| `models.json` | 艦種と GLB の対応（拠点の `base2` も `base.glb` を使う） |
| `models.js` | `node tools/pack-models.js` で作る、ビューア用にまとめたもの |

形を直すときは `designs.js` を変え、`gallery.html` で確かめて「GLBを全部書き出す」で書き出し、このフォルダに置いて `node tools/pack-models.js` を実行します。GLB をこのフォルダから消して `models.json` の行を消すと、その艦種はビューアのコードの簡単な形（`viewer3d-models.js`）に戻ります。

## 艦のモデルを差し替える

GLB（glTF のバイナリ）のモデルを用意すれば、艦種ごとに差し替えられます。

## モデルの決まり

- 前（艦首）が **+Z**、上が **+Y**。glTF の標準どおりです。Blender から glTF で書き出すと、Blender の -Y 前・+Z 上が自動でこの向きになります
- 大きさは気にしなくてよいです。いちばん長い辺を、艦種ごとの既定の長さ（光秒）に自動でそろえます
- マテリアル名に `team`・`accent`・`チーム` のどれかを含む部分は、陣営の色（人類は青、ザイレンは橙）で光らせます。エンジンの噴射口や発光帯に使うと、陣営が見分けやすくなります
- 1隻あたりのポリゴンは数千までが目安です（大規模会戦では同じ艦が100隻以上並びます）
- アニメーション・骨・モーフは使いません

向きや大きさの目安には、ビューアの「モデル」→「型紙」で書き出せる既定のモデルの GLB が使えます。

## 試しに使う（その場だけ）

ビューアの「モデル」で艦種を選び、「GLB」を押すか、.glb を枠に落とします。ビューアを閉じると元に戻ります。

## ずっと使う

1. このフォルダに GLB を置く（例: `narm.glb`）
2. `models.json` に書く

```json
{
  "entries": {
    "narm":   { "file": "narm.glb" },
    "guard":  { "file": "guard.glb", "rotation": [0, 180, 0] },
    "1:guard": { "file": "guard_zairen.glb" },
    "ナーム級": { "file": "narm.glb", "scale": 1.3 }
  }
}
```

キーは艦種ID（`narm` など。`シナリオ形式.md` の `types` のキー）か艦種名。`1:guard` のように「陣営:艦種」と書くと、その陣営の艦だけに使います（0 が人類側、1 が相手側）。探す順は「陣営:艦種ID」→「艦種ID」→「陣営:艦種名」→「艦種名」。

| 項目 | 意味 |
|---|---|
| `file` | このフォルダの GLB のファイル名（必須） |
| `rotation` | 向きの補正（度）。[x, y, z] |
| `scale` | 既定の長さに掛ける倍率 |
| `length` | 長さを光秒で直接決める（`scale` より優先） |
| `offset` | 位置の補正（長さ1にそろえたあとの単位）。[x, y, z] |

3. フォルダの一つ上で次を実行する

```
node tools/pack-models.js
```

`models.js` ができ、ビューアを開き直すと使われます。ビューアをファイルとして直接開く（ダブルクリック）と、ブラウザは同じフォルダの GLB を直接読ませてくれないので、この手順で `models.js` に埋め込んでいます。サーバー経由で開く場合は `models.json` と GLB をそのまま読むので、この手順は要りません。

## 既定の長さ（光秒）

実物の艦は数km（約0.00001光秒）で、戦場の縮尺では見えません。見やすさのために大きく誇張しています。ビューアの「表示」→「艦の大きさ」でも全体を変えられます。

| 艦種ID | 長さ | | 艦種ID | 長さ |
|---|---|---|---|---|
| node | 0.3 | | narm | 0.14 |
| guard | 0.16 | | garmes | 0.45 |
| comms | 0.18 | | elda | 0.26 |
| quiet | 0.24 | | base | 2.0 |
| picket | 0.11 | | base2 | 1.6 |
| artillery | 0.2 | | missile | 0.18 |
| carrier | 0.4 | | flagship | 2.6 |

ここにない艦種は 0.16 × 表示の大きさ（動かない拠点は 1.5 ×）です。
