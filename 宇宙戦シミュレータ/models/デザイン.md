# 艦のグランドデザイン

3Dビューアで使う艦のモデルの、見た目の決まり。2026-10-16 にユーザーと方向を決めた。人類統合機構は「軍艦＋幽子の輪」、ザイレンは「線と体節」。

設定資料（`思考実験まとめ.md`・`相手側_設定.md`）には艦の見た目の決まりがなく、相手の姿は未確定のまま。これはシミュレータの表示のための決まりで、設定資料ではない。設定の言葉（幽子・思考主推進機関・ウォード・レーン・片道の線）を形の手がかりにしている。

## 共通の決まり

| 項目 | 決まり |
|---|---|
| 向き | 前（艦首）が +Z、上が +Y（glTF の標準） |
| 大きさ | 長さ 10 前後で作る。ビューアが艦種ごとの長さ（`README.md` の「既定の長さ」）にそろえる |
| 材質 | 5つだけ。名前で役目が決まる。`hull`（船体の地の色）、`hull2`（暗い装甲・内側。両面を描く）、`trim`（金属の縁・部品）、`team_glow`（陣営の色で光る。ビューアが陣営の色に塗り替える）、`white_light`（白い灯り・窓） |
| 陣営の色 | 人類は青、ザイレンは橙。光る部分（`team_glow`）だけで出す。船体の色は陣営で固定 |
| 面の数 | 小型艦は 3,000〜5,000、中型は 5,000〜10,000、大型・拠点は 15,000 まで。大規模会戦では同じ艦が100隻以上並ぶ |
| 灯り | 白い灯りは小さく少なく（ビューアの光のにじみで白く飛ぶため）。陣営の光は帯や輪で見せる |
| 作り方 | `designs.js` の共通部品から組む → `gallery.html` で見る・GLB を書き出す → このフォルダに置いて `models.json` に書く → `node tools/pack-models.js` |

## 人類統合機構: 軍艦＋幽子の輪

**考え方**: 量産と規格化の軍。実用的な装甲の船体に、全艦共通の「幽子の輪」（思考主推進機関とウォードの発生器）を組み込む。輪の大きさ・数・形で、艦の役割が遠目にも分かる。

**形の言葉**
- 船体は、甲板が平らで、側面を面取りし、竜骨が細い六角の断面。艦首はくさび形にすぼまる
- 直線と面取り。左右対称。甲板の上に暗い装甲の帯、舷側に装甲帯と縦の継ぎ目
- 艦尾に箱形の機関部と釣鐘形の噴射口（奥が青く光る）
- 主砲（ライン系統の照射器）は丸い砲塔に短い砲身、先に青いレンズ

**色**: 船体 灰白（#a8b1bc）、装甲 暗い灰（#47505b）、金属 鋼（#8c98a6）、光 青

**共通部品**（`designs.js`）
| 部品 | 中身 |
|---|---|
| `hHull` | 船体（六角断面・くさびの艦首・甲板の装甲・舷側の帯・竜骨・継ぎ目・窓の列・艦首寄りの青い帯） |
| `hRing` | 幽子の輪（金属の輪の前後に青い光の帯、輪の上に発生器の塊と灯り、船体への支柱） |
| `hEngines` / `hEngine` | 機関部と噴射口 |
| `hTurret` | 主砲の砲塔 |
| `hBridge` | 艦橋（塔・窓の帯・帆柱と灯り） |
| `hGreebles` | 甲板の小さな機器（乱数は艦種ごとに固定） |

**艦種**
| 艦種 | 見分け方 |
|---|---|
| ガード級 | 量産の護衛艦。くさび形に小さな輪が1つ、主砲2基、機関2基、艦尾に斜めの放熱板 |
| ノード艦 | リンクの中枢。二重の輪を8本の棒の籠でつなぐ。背にリンクの送信塔（3つの輪と光る先端）、機関4基、主砲4基、艦尾に X 字のウォードの翼 |
| 通信艦 | 細身。両舷に大きな皿形アンテナ（幽子ペアの送受信）、背の帆柱、艦首から前へ伸びる2本の竿、灯りの列 |
| 静穏場艦 | 船体をぐるりと囲む大きな平たい輪（六つの発生器の塔）と、背の丸屋根。輪がいちばん大きい |
| 哨戒艦 | 細い針の船体、前へ長い探知の竿、両舷に薄い探知板、小さな輪 |
| 砲撃艦 | 背骨のような長い加速砲（2本の軌条と6つのコイル）が艦首から突き出す。弾倉の箱 |
| ミサイル艦 | 幅広の船体。甲板に発射筒の箱が2つ（升目のふた）、両舷に増設の発射器 |
| 無人機母艦 | 平たく幅広。暗い発着の甲板（中央に青い灯りの列）、両舷に格納庫の口と無人機の架台 |
| 拠点 | 縦の塔を軸に、大きな居住の輪（12の区画・砲塔）、幽子の輪、4本の腕、塔の上に妨害場の発生器の丸屋根 |

## ザイレン: 線と体節

**考え方**: レーン（線）の上を行く民。艦は節（体節）が一列に連なった細長い形で、節の継ぎ目が橙に光る。背骨の上を片道の線の光が走り、腹の下にはレーンに乗る2本の軌条がある。生き物らしさとレーンの機能の両方を見せる。少し非対称。レーンで跳ぶので大きな噴射口はない。

**形の言葉**
- 節は多面の紡錘形（角ばった殻）。少し平たい。上に暗い甲殻の板が重なり、金属の稜線が通る
- 節と節のあいだは細い首で、光る輪がはまる
- 艦首は二股の角と、そのあいだの片道の線の発射口（光る玉と金属の輪）
- 艦尾は光る尾の玉と小さな安定板

**色**: 殻 暗い褐色（#6a5040）、甲殻 黒褐（#2a201a）、金属 青銅（#b08658）、光 橙

**共通部品**（`designs.js`）
| 部品 | 中身 |
|---|---|
| `zBody` | 節の並び（艦尾から艦首へ）。継ぎ目の光る輪、背骨の線、腹の下の軌条を付ける |
| `zSeg` / `zJoint` | 節（紡錘形の殻・甲殻・稜線）と継ぎ目 |
| `zProngs` | 艦首の二股の角と片道の線の発射口 |
| `zTail` | 艦尾の光る尾と安定板 |
| `zEmitter` | 背に載る片道の線の照射器（小さな角と光） |

**艦種**
| 艦種 | 見分け方 |
|---|---|
| ナーム級 | 小型・多数。3つの節がすぼまっていく矢じり形。二股の角、後ろの翼、片側だけの探知のこぶ |
| ガルメス級 | 大型の幹線艦。7つの太い節の両脇に、僚艦を運ぶ揺りかご（軌条と、運ばれる小さな節の荷）。背に照射器4基 |
| エルダ級 | 敷設艦。艦首に長い針（レーンの放出器）と、それを巻く糸巻きの輪。胴の真ん中に太い巻き胴 |
| オルドラ級 | 巨大旗艦。9つの節（真ん中の3つは格納庫で、両脇に光る口）、艦首の長い攻城線砲（コイルの輪）、艦尾のレーンの錨（大きな輪を4本の腕で支える）、背の光る線と照射器 |

## 新しい艦種を足すとき

1. 陣営の共通部品から組む。人類なら「どんな幽子の輪を持つか」、ザイレンなら「節をいくつ・どんな太さで並べ、何を載せるか」で役割を見せる
2. `designs.js` の `HUMAN` か `ZAIREN` に関数を足し、`LIST` に艦種ID・陣営・名前を書く
3. `gallery.html` で形を確かめ、「この艦のGLB」で書き出す（ブラウザで開く。three.js をネットから読む）
4. GLB をこのフォルダに置き、`models.json` に艦種IDとファイル名を書いて、一つ上のフォルダで `node tools/pack-models.js`
5. ビューアでの大きさは `viewer3d-models.js` の `BASE_LENGTH` に艦種IDと長さ（光秒）を足す（なければ 0.16 × 表示の大きさ）
