# 宇宙戦シミュレータ 操作方法

## 1. 開く

1. ZIP を展開する
2. `宇宙戦シミュレータ` フォルダの `index.html` をダブルクリックする（Edge や Chrome で開く）

同じフォルダの `engine.js`・`presets.js`・`ui.js` が必要なので、フォルダごと扱う。インターネットにつながっていなくても動く。

## 2. 画面の見方

- **地図（中央）**: 艦は形と色で表す。色が陣営、形が艦種（左下の凡例を参照）。距離の単位は光秒（1光秒 ≈ 30万km）。右下に1目盛りの長さが出る
- **左上**: 時刻（T+時:分:秒）と、陣営ごとの戦力（初期を100%とした残り。まだ到着していない増援も含み、離脱した艦は除く）・残っている隻数。「情報共有なし」「全軍撤退中」もここに出る
- **地図の記号**
  - 艦のまわりの細い輪: ロックタイム中（輪の長さが残り）
  - 点線と丸: ジャンプ中（点線の先が行き先）
  - 緑の円: 妨害場（中ではジャンプできない）。展開中は艦のまわりに緑の弧が伸びる
  - 陣営色の線: レーン。灰色の点線になった部分は妨害場で寸断されている
  - 細い線: 射線（薄いのは外れ）。細かい点線はシェル、破線は誘導弾（着いた時に出る）。×: 撃沈
  - 陣営色の塗った円: シェルの爆発（半径0.2光秒）
  - 陣営色の小さな点: 飛んでいる無人機。小さな ×（陣営色）: 迎撃で撃ち落とした誘導弾・無人機
  - 太い線: 貫く線（ザイレンの旗艦）。艦のまわりの破線の輪は溜めている最中、太い輪は溜め終わって撃つ向きを待っている
  - 「積30」: 方舟（旗艦）が積んでいる艦の数。積まれている艦は地図に出ない
  - 艦の下の2本の棒（拡大時）: 上がウォード、下が船体耐久
- **艦にマウスを重ねる**と、耐久・状態（ロックタイムの残り、展開中など）・標的が出る
- **下**: 時間のスライダー、戦力の推移グラフ（クリックでその時刻へ）、最新の出来事

## 3. 艦を置く

1. 右の「配置」タブの「置く艦」で、陣営（人類統合機構 / ザイレン）を選ぶ
2. 艦種のボタンを押す（道具が自動で「配置」になる）
3. 隻数・間隔（光秒）・隊形（塊・横一列・縦一列・円）を決める
4. 地図をクリックすると置ける

## 4. 選ぶ・動かす・消す

道具「選択」（キー V）で:

- クリックで1隻、ドラッグで囲むと複数を選ぶ。Shift を押しながらで追加
- 選んだ艦をドラッグで動かす
- Delete で削除。Ctrl+Z（または上の「元に戻す」）で戻す
- 地図の移動は右ドラッグか中ボタンドラッグ、拡大縮小はホイール。F で全体表示（選んでいればその艦へ）

## 5. 艦の行動を決める

艦を選ぶと、右の「選んだ艦」で次を変えられる。何も選ばなければ艦種の設定どおりに動く。

| 項目 | 内容 |
|---|---|
| 陣営 | どちらの陣営か |
| 行動 | 突撃 / 射程維持 / 持ち場防衛 / 要艦の護衛 / 艦隊に随伴 / 静止 |
| 狙う敵 | 最寄りの敵 / 弱った敵（集中射撃）/ 火力の高い敵 / 要艦 / 高価な敵 |
| 移動 | 自動（早く着くほう）/ ジャンプ優先（ロック明けを待つ）/ 通常航行のみ |
| 撤退する耐久 | 船体耐久がこの%を下回ると離脱を図る |
| 出現時刻 | ○分後にジャンプで到着する増援にする |
| ジャンプ直後から始める | ロックタイム中の状態で始める（到着したばかりの艦隊） |
| 目標地点 | 「目標地点を指定」を押して地図をクリック。隊形を保ったまま行き先が決まる。着いたらそこが持ち場になる |
| 積まれる艦 | 方舟（「艦を積んで運ぶ」がオンの艦種。ザイレンの旗艦）に積む。同じ陣営の方舟があるときだけ出る。積んだ艦は地図から消え、方舟の横に「積○」と出る。降ろすには方舟を選んで「積んでいる艦を降ろす」を押す（方舟の横に並ぶ） |

## 6. レーンと文字

- 道具「レーン」（キー L）: クリックで点を打ち、ダブルクリックか Enter で確定。レーンは「置く艦」で選んでいる陣営のものになる。既存のレーンの点の近くは吸い付いてつながる
- レーンは「選択」でクリックすると選べ、陣営の入れ替えや削除ができる
- 道具「文字」（キー T）: クリックした位置に地名などを置く。ドラッグで動かせ、ダブルクリックで書き換え

## 7. 艦の性能を変える（「艦種」タブ）

艦種を選ぶと、その艦種の数値が並ぶ。変えると地図上のその艦種すべてに効く。

- 耐久: 船体耐久、ウォード容量、ウォード回復、回避
- 兵装: 威力、射程、発射間隔、命中率、射程端での命中低下、砲門の数（目安の「1分あたりの損害」も出る）。砲門が複数あると、射程内の別々の敵を同時に撃つ（拠点は6門）
- 機動: 速さ、探知距離、ジャンプ方式（任意座標 / レーン上のみ / しない）、ロックタイム
- 既定の行動: 行動、狙う敵、撤退する耐久
- 特殊能力: リンク（ノード艦）、妨害場（静穏場艦・拠点）、通信（通信艦）、レーン敷設（エルダ級）
- 副兵装: 主砲とは別に撃つ兵器。種類（ライン型・シェル型・誘導弾・無人機）を選ぶと、その種類に要る項目だけが出る。拠点・砲撃艦はシェル（超遠距離から敵の群れへ見越しで撃ち込む実体弾。射程60光秒、半径1光秒の爆発で中の敵すべてを一撃、弾数あり）を積んでいる。弾は味方の拠点の近くで補充される。目安（届くまでの時間、弾数、爆発の範囲）も出る
- 迎撃: 近くに来た誘導弾・無人機を撃ち落とす（ガード級・ノード艦・拠点がもつ）
- 艦にマウスを重ねると、補充に戻っている艦は「弾の補充に戻っている」と出る

「新しい艦種」「複製」「削除」で艦種を増減できる。削除は2回押すと確定する。

## 8. 陣営と全体の設定（「陣営と設定」タブ）

- 陣営: 名前、色、反応時間（遠くの敵を見つけてから陣営として動くまでの遅れ）、情報共有の方式、全軍撤退ライン
- 全体: 制限時間、計算の刻み、ジャンプにかかる時間、ジャンプを使う最短距離、到着誤差、レーンに乗れる距離、乱数シードなど
- シナリオのメモ: 画面上部に出る説明文

## 9. 再生と結果

- 「再生」（Space）で時間が進む。速さは「1秒で5分」などから選ぶ
- スライダーで前後に動かせる。「結果まで計算」で決着まで一気に進む
- 「交戦を追う」がオンだと、撃ち合っている場所へ視点が寄る（地図を手で動かすと切れる）
- 「結果」タブ: 勝敗、艦種ごとの撃沈・離脱・残存、出来事の一覧（クリックでその時刻へ）
- 計算の途中で配置や性能を変えると、計算は捨てて T=0 の編集に戻る。「編集に戻る」でも戻れる

## 10. 勝率を出す（複数回の試行）

「結果」タブの「複数回の試行」で回数（10〜100）を選んで「試行する」。乱数シードを変えて何度も戦わせ、勝率・平均残存戦力・艦種ごとの平均損失を出す。命中判定と到着誤差だけが回ごとに変わる。

## 11. 保存と読込

- 画面の状態はブラウザに自動で保存される（同じパソコン・同じブラウザなら、次に開いたときも残っている）
- 「保存・読込」: いまのシナリオを JSON で書き出す。「ファイルに保存」で .json ファイルにできる
- **Claude Code が作ったシナリオを見るとき**: 「保存・読込」→「ファイルを開く」でその .json を選ぶ
- 上の「プリセットを開く…」で用意したシナリオに切り替えられる（「元に戻す」で前に戻せる）

## 12. キー操作

| キー | 動作 |
|---|---|
| V / P / G / L / T | 道具: 選択 / 配置 / 目標 / レーン / 文字 |
| Space | 再生・停止 |
| F | 全体表示（選んでいればその艦へ） |
| Delete | 選んだものを削除 |
| Ctrl+Z | 元に戻す |
| Enter / Esc | レーンの確定 / 取り消し・選択の解除 |

## 13. 3Dで見る

1. 2Dの画面で配置とシードを決め、時間軸の「3Dで見る」を押す（いまの時刻から始まる）
2. 別のタブで3Dビューアが開く。計算に数秒かかる（大規模会戦で約2秒）
3. 下の操作バーで再生・停止、時刻、速さ、カメラを選ぶ

インターネット接続が必要です（3D描画の部品を読み込むため）。

| 操作 | 動作 |
|---|---|
| Space | 再生・停止 |
| 1〜5 | カメラ: 監督 / 交戦 / 追尾 / 俯瞰 / 自由 |
| W A S D | 自由カメラで前・左・後ろ・右へ動く（押すと自由カメラになる） |
| E / Q | 自由カメラで上 / 下へ動く。Shift を押しながらで速く |
| ← → | 時刻を戻す・進める |
| F | 全画面 |
| R | 録画の開始・停止 |
| H | 時刻と戦力の表示を隠す |
| M | 効果音の入・切 |
| 艦をクリック | その艦の状態を出す。「この艦を追う」かダブルクリックで追尾 |
| ホイール | 自由カメラに切り替えて寄る・引く。ドラッグで回す、右ドラッグで動かす |

右上のボタン:
- **シナリオ**: プリセットやシナリオの JSON を開く、シードを変えて計算し直す、2Dの画面から受け取り直す
- **モデル**: 艦種ごとに GLB のモデルに差し替える（その場だけ）。「型紙」で既定のモデルを GLB に書き出せる。ずっと使う手順は `models/README.md`
- **表示**: シネマの帯・字幕・射線・妨害場・レーン・地名・艦名・ロックタイムの輪・残弾の点・星雲・フィルムの質感・光のにじみ・高さのずれ・効果音の音量・環境音・群れの横の散らし・艦の大きさ
- **音**: 効果音の入・切（「音 入」「音 切」）。音量と環境音（低いうなり）は「表示」で変えられる。ブラウザの決まりで、最初に画面をクリックするかキーを押すまでは鳴らない
- **録画**: 押しているあいだの画面を動画にする。もう一度押すと保存される（`uchusen3d_日付_時刻.mp4`）。効果音が入なら音も入る

シェルは、発射した艦に金色の閃光が出て、白金色の弾頭と長い航跡で飛びます。着弾すると爆発の範囲（半径1光秒）が半透明の球で広がり、「撃沈 10」のような戦果の札が浮かびます。誰も範囲にいなければ、淡い青の球と「外れ」の札です。艦をクリックすると、副兵装の射程が球と平面の輪で、飛んでいる自分のシェルの着弾予定点が小さな球で出て、カードに残弾が出ます。シェルを積む艦の上には残弾の点が並びます（明るい点が残り、暗い点が撃った分）。誘導弾・無人機は光る点と短い尾で見せます（誘導弾は弧を描き、迎撃されると途中で光って消えます）。

ザイレンの旗艦（オルドラ級）は、両脇に格納庫、艦首に輪の並ぶ長い砲身、艦尾にレーンの錨の大きな輪を持つ巨大な艦です。進みながら後ろにレーンを引き、艦尾の輪がゆっくり脈打ちます。貫く線を溜めている間は、艦首に光が集まって輪が縮んでいき、撃つと太い光の筒が射程いっぱいまで一気に伸び、線の上の敵に火花が散って「撃沈 3」のような札が出ます。積んでいた艦は、旗艦から短い光の筋とともに出てきます。効果音は、溜め（低い唸りが共鳴しながら高まる）、発射（空気が裂けるような割れと、唸り続ける太い光の轟音）、発艦（留め具の外れる金属音と短い噴射）です。

効果音は音声ファイルを使わず、ブラウザの中で合成しています（宇宙に音はありませんが、映画のように鳴らしています）。重く聞こえるように、低い音を芯にして軽く歪ませ、全部の音を広い空間の響きに少し送っています。主砲（人類は芯のある重い発砲音に金属の響き、ザイレンは低く唸る生き物のような音）、撃沈（火の玉・腹に来る衝撃・地鳴り・破片。大物は誘爆が続き、船体がきしむ）、シェルの発射（大砲のような「ドン」と装填の音）と着弾（衝撃が2度来て、長い地鳴りが震える）、ジャンプの出入り（消えるときは吸い込まれて「ボン」、現れるときは落ちてきて重い衝撃）、レーンの移動、妨害場の完成（金管のような低い和音がふくらむ）と消滅、誘導弾、迎撃、無人機の音があります。左右は画面での位置、大きさはカメラからの距離で変わり、遠い音はこもって響きが多めになります。早送りでは、たくさん起きた音を種類ごとに数本にまとめて鳴らします。高さは見た目だけのずれです（計算は平面）。計算では大群がほぼ一点に寄ることがあるので、混んでいる艦は水平にも少し散らして見せています（「群れの横の散らし」で強さを変えられ、0 で計算どおりの位置）。艦の大きさも見やすさのために誇張しています。

## 14. Claude Code にいじってもらう

1. ZIP を展開したフォルダ（`宇宙戦シミュレータ`）で Claude Code を起動する
2. `CLAUDE.md` に作業のルールと道具の使い方が書いてあるので、Claude Code はそれを読んで動く
3. たとえば次のように頼む
   - 「S星系外縁B（sB）で、静穏場艦のウォードをいくつにすれば人類が勝つか調べて」
   - 「正面衝突で、ザイレンの反応時間を5分から30分まで5分刻みで変えたときの勝率を表にして」
   - 「S星系外縁Aで、人類の出る位置をH2から5光秒離したらどうなるか。結果のシナリオを保存して」
   - 「ナーム級の回避を0%にした版と30%の版を、それぞれ50回ずつ比べて」
   - 「大規模会戦（grand）で、人類の増援があと30分早く着いたら勝率はどう変わる？」
4. Claude Code が保存したシナリオ（`scenarios/` などの .json）は、画面の「保存・読込」→「ファイルを開く」で読み込んで、再生して見られる

数値（耐久・火力など）を変えるのは自由。計算のルールそのもの（`engine.js`）を変えるときは、Claude Code が先に確認してくる決まりにしてある。

## 15. 自分でコマンドを使う

Node.js が入っていれば、フォルダでコマンドを打って回せる。

```
node tools/battle.js --list                                   プリセットの一覧
node tools/battle.js sB                                       20回戦わせて勝率と損害
node tools/battle.js sB --runs 50 --set types.quiet.shield=6000
node tools/battle.js basic --seed 3 --events                  1回分の経過
node tools/sweep.js sB --param types.quiet.shield --values 2500,4000,6000,8000
node tools/battle.js sB --set types.narm.evasion=0 --save scenarios/回避なし.json
```

`--set` の値は内部の単位（秒・光秒・c・0〜1の割合）で書く。画面の「45分」は 2700、「30%」は 0.3。キーの一覧は `シナリオ形式.md`。

## 16. 困ったとき

- **画面が真っ白・動かない**: `index.html` と同じフォルダに `engine.js`・`presets.js`・`ui.js` があるか確かめる
- **前の配置が消えた**: 自動保存はブラウザごと。別のブラウザや別のパソコンでは引き継がれない。残したいものは「保存・読込」でファイルにしておく
- **コマンドの日本語が文字化けする**（古いコマンドプロンプト）: `chcp 65001` を打ってから実行する。Windows Terminal なら通常は不要
- **結果が毎回同じ**: 乱数シードが同じなら同じ結果になる。ばらつきを見るときは複数回の試行を使う
- **3Dビューアが「three.js を読み込めませんでした」で止まる**: インターネットにつながっているか確かめる。会社のネットワークなどで cdn.jsdelivr.net が止められていると動かない
- **3Dビューアが2Dの画面の配置を受け取らない**: 2Dの画面と同じブラウザで開いているか確かめる（受け渡しはブラウザの保存領域を使う）。だめなら2Dの画面の「保存・読込」で JSON をファイルにし、ビューアの「シナリオ」→「ファイルを開く」で読む
- **3Dが重い**: 「表示」で光のにじみを0に、フィルムの質感を切る。ブラウザのウィンドウを小さくしても軽くなる
