# シナリオ JSON の形式

画面の「保存・読込」で書き出す JSON と、`tools/battle.js` などが読む JSON は同じ形。`scenarios/` にプリセットの JSON がある。

**単位は内部の単位**で書く。時間は秒、距離は光秒、速さは c（光速の何倍か）、割合は 0〜1。画面では「分」や「%」で見せている項目があるので、書き換えるときは換算する（例: 画面のロックタイム 45分 → `2700`、画面の回避 30% → `0.3`）。

座標は x が右向き、y が**下向き**（画面の下が y の大きい方）。

## 全体

```json
{
  "version": 1,
  "name": "シナリオ名",
  "note": "画面の上に出る説明",
  "settings": { ... },
  "sides": [ {人類側}, {相手側} ],
  "types": { "艦種ID": { ... }, ... },
  "units": [ { ... }, ... ],
  "lanes": [ { "side": 1, "pts": [[x, y], [x, y], ...] } ],
  "marks": [ { "x": 0, "y": 0, "text": "地名" } ]
}
```

足りない項目は既定値で補われ、おかしな値は既定値に直される（`engine.js` の `normalizeScenario`）。

## settings（全体の設定）

| キー | 意味 | 単位 | 既定値 |
|---|---|---|---|
| `timeLimit` | 制限時間 | 秒 | 14400 |
| `dt` | 計算の刻み（1〜60） | 秒 | 5 |
| `jumpTime` | ジャンプにかかる時間 | 秒 | 20 |
| `jumpMin` | ジャンプを使う最短距離 | 光秒 | 15 |
| `arrivalError` | 到着誤差（最大） | 光秒 | 0.1 |
| `laneAccess` | レーンに乗れる距離 | 光秒 | 2 |
| `laneJumpTime` | レーンジャンプにかかる時間 | 秒 | 5 |
| `laneGap` | レーンを区切る間隔（計算用） | 光秒 | 3 |
| `retarget` | 標的を見直す間隔 | 秒 | 15 |
| `drawMargin` | 時間切れで引き分けにする残存戦力の差 | 0〜1 | 0.05 |
| `resupplyRange` | 弾を補充できる距離（味方の拠点から） | 光秒 | 10 |
| `resupplyTime` | 1発の補充にかかる時間 | 秒 | 120 |
| `spacing` | 艦どうしの最小間隔。これより近い2隻は押し離す。0 なら重なってもよい | 光秒 | 0.3 |
| `stallBreak` | 膠着を破るまでの時間。一度撃ち合いが始まったあと、この時間どちらも撃たず、敵の位置が分かっていると、持ち場防衛・護衛・随伴の艦が突撃に切り替える（拠点・拠点の守備隊・妨害場やレーン敷設の艦・武器のない艦はそのまま）。0 なら破らない | 秒 | 1800 |
| `chaseGiveUp` | 追撃をあきらめるまでの時間。標的が射程の外にいて、この時間追っても1割も近づけなければ、その標的をやめる（30分は選ばない）。撤退中の敵は除く。0 ならあきらめない | 秒 | 1200 |
| `seed` | 乱数シード（複数回試行はここから順に） | | 1 |

## sides（陣営。0 が人類側、1 が相手側）

| キー | 意味 | 値 |
|---|---|---|
| `name` | 名前 | 文字 |
| `color` | 色 | `blue` / `orange` / `aqua` / `violet` / `red` / `yellow` |
| `reaction` | 反応時間（遠くの敵を見つけてから陣営として動くまで） | 秒 |
| `sharing` | 情報共有 | `always`（常に）/ `comms`（通信艦がいるときだけ）/ `local`（共有しない） |
| `retreatBelow` | 全軍撤退ライン（割合）。戦力（初めを1として、まだ着いていない援軍も含める）がこれを下回ると全艦が撤退 | 0〜1。0 ならこの判定はしない |
| `retreatCost` | 全軍撤退ライン（残りの戦力）。戦場にいる艦（方舟に積まれている艦を含む。まだ着いていない援軍は数えない）の「コスト × 耐久の割合」の合計がこれを下回ると全艦が撤退。一度この値以上になってから働く | コスト。0 ならこの判定はしない（既定 0） |
| `retreatMode` | `retreatBelow` と `retreatCost` の両方が 0 より大きいときの組み合わせ | `either`（どちらかを下回ったら。既定）・`both`（両方を下回ったら） |

### 行動（`ai`）

| 値 | 意味 |
|---|---|
| `assault` | 突撃: 標的の射程の85%まで近づいて撃つ |
| `kite` | 射程維持: 射程の8〜9割の距離を保つ。近づかれたら下がる |
| `hold` | 持ち場防衛: 持ち場（初期位置か、到着した目標地点）から一定距離の中だけで戦う（貫く線を持つ艦は、貫く線の射程までの敵を狙う） |
| `escort` | 要艦の護衛: 60光秒以内でいちばん近い要艦（特殊能力を持つ艦）に付き添い、近づく敵を迎え撃つ。要艦が跳ぶと同じ先へ跳ぶ。近くに要艦がいなければ突撃と同じ |
| `follow` | 艦隊に随伴: いちばん近い味方の武装艦の塊（20光秒以内）の、中心の少し後ろに付いていく |
| `static` | 静止: 動かずに撃つ |

### 狙う敵（`priority`）

| 値 | 意味 |
|---|---|
| `nearest` | 最寄りの敵 |
| `weakest` | 弱った敵（集中射撃になりやすい） |
| `threat` | 火力の高い敵 |
| `key` | 要艦（リンク・妨害場・通信・敷設のどれかを持つ艦） |
| `cost` | 高価な敵 |

`nearest` 以外も距離は考える。遠すぎる「よい標的」より近い標的を選ぶことがある。

## units（艦。1隻ずつ）

```json
{ "type": "guard", "side": 0, "x": 300.2, "y": -1.5,
  "ai": "hold", "priority": "key", "move": "jump", "retreatAt": 0.3,
  "appear": 1800, "locked": true, "goal": [300.3, -2.2] }
```

| キー | 意味 | 値 |
|---|---|---|
| `type` | 艦種ID | `types` のキー |
| `side` | 陣営 | 0 / 1 |
| `x`, `y` | 初期位置 | 光秒 |
| `ai` | 行動（省くと艦種の設定） | 上の表 |
| `priority` | 狙う敵（省くと艦種の設定） | 上の表 |
| `move` | 移動方式（省くと `auto`） | `auto`（早く着くほう）/ `jump`（ロック明けを待って跳ぶ）/ `cruise`（通常航行のみ） |
| `retreatAt` | 撤退する耐久（省くと艦種の設定） | 0〜1 |
| `appear` | 出現時刻。0 より大きいと、その時刻にジャンプで到着する増援になる | 秒 |
| `locked` | ジャンプ直後（ロックタイム中）から始める | true |
| `goal` | 目標地点。着いたらそこが持ち場になる | [x, y] |
| `aboard` | 積まれる艦（方舟）。`units` の何番目（0 から）の艦に積まれるか。積む艦は `hangarOn` がオンで同じ陣営のもの。積まれた艦の位置は無視され、方舟の位置から始まる。積める数を超えた分は積まれない | 番号 |

## lanes（レーン）

`side` の陣営の、`jump` が `lane` の艦だけが使える。`pts` は折れ線の点。端点が同じ陣営の別のレーンの近く（`laneAccess` 以内）にあるとつながる。妨害場の中の部分は寸断される。

## marks（地図の文字）

`{ "x": 300, "y": 0, "text": "H2" }`。計算には関係しない。

## Node から直接使う

```js
const E = require('./engine.js');
const P = require('./presets.js');
const scn = P.SCENARIOS.find((s) => s.id === 'sB').make();   // または JSON.parse(fs.readFileSync(...))
scn.types.quiet.shield = 6000;
const r = E.runOnce(scn, 1);           // シード 1 で決着まで
console.log(r.text, r.sides[0].byType);

const S = E.createSim(scn, { seed: 1 });  // 途中を見たいとき
E.runUntil(S, 3600);                       // 1時間まで進める
console.log(S.units.filter((u) => u.alive).length, S.events.slice(-5));
```

`runOnce` の戻り値: `winner`（0 / 1 / 引き分けは -1）、`reason`（`annihilation` 全滅 / `retreat` 撤退 / `time` 時間切れ / `mutual`）、`text`、`t`（決着の秒）、`sides[k]`（`byType` に艦種ごとの `n` `lost` `escaped` `left` `pending`、`kept` 残存戦力、`onField` 戦場に残る戦力、`dealt` 与えた損害）。
