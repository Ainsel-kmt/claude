# 宇宙戦シミュレータ

好きな艦を好きな場所に置き、どちらが勝つかを計算するツール。艦は行動のアルゴリズムに従って動き、性能の数値はすべて画面から変えられる。宇宙戦思考実験の設定（ジャンプとロックタイム、ノード艦のリンク、妨害場、ザイレンのレーン）を組み込んである。

`会戦ビュワー.html`（S星系外縁の会戦を時系列で見るだけのもの）を作り直した後継。旧ビュワーはそのまま残してある。

## 開き方

`index.html` をブラウザで開く（ダブルクリックでよい）。サーバーも外部ライブラリも要らない。フォントだけは、ネットにつながっていれば Google Fonts から読み、つながっていなければ手元の日本語フォントで表示する。

同じフォルダの `engine.js`・`presets.js`・`ui.js` も一緒に置いておくこと。

画面の操作は `操作方法.md`、シナリオ JSON の形式は `シナリオ形式.md` にまとめてある。

## 3Dで見る

2Dの画面の時間軸にある「3Dで見る」を押すと、別のタブで3Dビューア（`viewer3d.html`）が開き、同じ配置・同じシードの戦いを映画的な3Dで再生する。ビューアは同じ計算エンジンで戦いを計算し直すので、結果は2Dの画面とまったく同じになる。

- **インターネット接続が必要**（描画に three.js 0.170 を CDN から読む）。2Dの画面はこれまでどおりネットなしで動く
- **カメラ**: 監督（見どころを自動で切り替える）／交戦（いちばん激しい撃ち合いを追う）／追尾（クリックで選んだ艦を後ろから追う）／俯瞰（戦場全体）／自由（マウスで回す・寄る・動かす）
- **演出**: 光速で伸びる射線、ウォードに当たる光と船体の火花、撃沈の爆発・衝撃波・破片、ジャンプの閃光、レーンジャンプの光の筋、展開して膨らむ妨害場、流れるレーン、星雲と恒星、光のにじみ、フィルムの質感、シネマの帯と字幕
- **高さ**: 計算は平面だが、見た目のために艦ごとに高さをずらしている。部隊（陣営×艦種）ごとに役割で決まる層に2〜3段の段差を付け、艦ごとに小さな乱数を足す。距離は2Dの画面と少しずれて見える。「表示」で大きさを変えられる
- **艦の大きさ**: 実物（数km）は戦場の縮尺では見えないので、0.2〜3光秒に誇張している。遠くでは光る点で見せる
- **モデル**: 艦種ごとに GLB に差し替えられる。決まりと手順は `models/README.md`
- **録画**: 「録画」を押しているあいだの画面（字幕と帯を含む）を動画にする（Chrome・Edge なら mp4、それ以外は webm）。再生と同じ速さで録るので、長い戦いは速さを上げてから録る
- 2Dの画面を通さずに、`viewer3d.html?preset=grand&seed=3` のようにプリセットとシードを指定して開くこともできる

## Claude Code やコマンドで回す

このフォルダで Claude Code を起動すると、`CLAUDE.md`（作業のルールと道具の使い方）を読んで動く。Node.js があれば、自分でもコマンドで戦闘を回せる。

```
node tools/battle.js sB                                    # 20回戦わせて勝率と損害
node tools/battle.js sB --set types.quiet.shield=6000      # 値を書き換えて回す
node tools/sweep.js sB --param types.quiet.shield --values 2500,4000,6000,8000   # 値を振って比べる
node tools/battle.js sB --set ... --save scenarios/試し.json                      # 画面で読めるシナリオを保存
```

`--set` の値は内部の単位（秒・光秒・c・0〜1 の割合）で書く。`node tools/battle.js --help` で使い方が出る。

## できること

- **配置**: 陣営と艦種を選び、地図をクリックして置く。隻数・間隔・隊形（塊・横一列・縦一列・円）を選べる。ドラッグで囲んで複数選択、ドラッグで移動、Delete で削除、Ctrl+Z で元に戻す
- **行動**: 選んだ艦ごとに、行動（突撃・射程維持・持ち場防衛・要艦の護衛・艦隊に随伴・静止）、狙う敵（最寄り・弱った敵・火力の高い敵・要艦・高価な敵）、移動方式、撤退する耐久、出現時刻（増援）、目標地点を変えられる
- **性能**: 「艦種」タブで、耐久・ウォード・回避・射程・威力・発射間隔・命中率・速さ・探知距離・ジャンプ方式・ロックタイムと、特殊能力（リンク・妨害場・通信・レーン敷設）の数値を変えられる。艦種の追加・複製・削除もできる
- **地形**: レーン（ザイレンの航路）を描ける。地名などの文字も置ける
- **陣営**: 名前・色・反応時間・情報共有の方式・全軍撤退ラインを変えられる
- **再生**: 再生・一時停止・スライダーでの巻き戻し・「結果まで計算」。「交戦を追う」で撃ち合っている場所へ視点が寄る。艦にマウスを重ねると、耐久・ロックタイムの残り・標的などが出る
- **結果**: 勝敗、艦種ごとの撃沈・離脱・残存、戦力の推移グラフ、時刻つきの出来事一覧（クリックでその時刻へ）
- **勝率**: 乱数シードを変えて10〜100回戦わせ、勝率・平均残存戦力・艦種ごとの平均損失を出す
- **保存**: 自動でブラウザに保存される。「保存・読込」で JSON の書き出し・読み込みもできる

## 計算のしくみ

単位は、距離が光秒（1光秒 ≈ 30万km）、時間が秒、速さが c。既定では5秒刻みで進める。

- **射撃（主砲）**: 射程内の標的に発射間隔ごとに1発撃つ。命中率 = 命中率 ×（1 − 射程端での命中低下 × 距離/射程）×（1 − 相手の回避）。当たるとウォード、次に船体耐久が減る。ウォードは毎秒回復する。砲門が複数ある艦（拠点など）は、標的のほかに射程内の敵を近い順に1門ずつ撃ち、敵が門の数より少なければ余った門は標的に重ねる
- **副兵装**: 主砲とは別の間隔で撃つ兵器を1つ積める。種類は5つ。損害のうち「ウォードを素通りする割合」はウォードに止められず船体に直接当たる
  - ライン型: 主砲と同じく光速で一瞬に当たる
  - シェル型（実体弾）: 超遠距離から敵の群れへ撃ち込む面制圧。見えている敵それぞれについて、いまの向きと速さのまま進むと弾が出会う点を解き（見越し）、その敵のまわり（爆発半径の中）にいまいる敵のコストの合計（コスト × 数）がいちばん大きい点を狙う。弾は「距離 ÷ 弾の速さ」の時間をかけて飛び、着いた点で爆発する。撃たれる側は気づかないので、外れるのは針路や速さを変えたとき（たとえば目標に着いて止まった）だけ。命中率は「狙った点に届く割合」で、外れると狙いから爆発半径の1〜2倍ずれた点で爆発する。「撃つのに要る敵の数」より小さい群れには撃たない。2発以上を一度に撃つときは、まだ狙っていない群れへ順に撃つ
  - 誘導弾: 届くまで時間がかかるが、標的を追うので避けられない。着く直前に、標的の近くにいる相手の迎撃艦が撃ち落としを試みる
  - 無人機: 発進して標的の0.3光秒まで飛び、そこで10秒ごとに1発撃つ。稼働時間が尽きると消える。標的が沈むと3光秒以内の別の敵へ移る。飛んでいる間ずっと、近くの相手の迎撃艦に狙われる
  - 貫く線（ザイレンの旗艦）: 射程の中に見えている敵がいれば溜めに入る。溜めの時間が過ぎたら、射程内で見えている敵それぞれへ向けた線のうち、線の太さの中に入る敵のコストの合計（コスト × 数）がいちばん大きい向きへ撃ち、射程いっぱいまで伸びる線の太さの中にいる敵すべてに損害を与える（命中率は1隻ずつ。回避で下がる。味方は巻き込まない）。光速で一瞬に届き、撃たれる側は気づかない。溜めている間は動けない。溜め終わって射程の中に敵がいなければ、溜めたまま待つ（そのあいだは動ける）。撤退に移ると溜めは捨てる。撃ってから「発射間隔」が過ぎると次の溜めに入れる
  - 主砲のない艦（威力0）は、副兵装の射程で動く（突撃や射程維持の距離）
  - 爆発: 「爆発の半径」があるシェル・誘導弾は、爆発すると半径の中の敵すべてに威力いっぱいの損害を与える（減衰なし。味方は巻き込まない）。シェルは狙った点で、誘導弾は当たった艦の位置で爆発する
  - 撃つ見込み（ライン型・誘導弾）: 当たる見込み（命中率・回避から計算。迎撃は数えない）がこれ以上の敵にだけ撃つ
  - 弾数: 撃ち尽くすと撃てない。味方の拠点（動かない艦）から「弾を補充できる距離」（既定10光秒）の中にいるあいだ、「1発の補充にかかる時間」（既定2分）ごとに1発ずつ補充される。拠点は自分で補充する
  - 補充に戻る: 艦種で「弾が尽きたら補充に戻る」がオンの艦は、撃ち尽くすといちばん近い味方の拠点へ向かい、満タンになってから戦いに戻る
- **動くハブ**（ザイレンの旗艦）: 進みながら後ろにレーンを敷く。レーンの端はいつもこの艦のところにあるので、そのレーンにつながったレーン網の味方は、この艦のそばまでレーンで跳べる。曲がったところは折れ点として残る。敷いているあいだの通常航行は「敷設の速さ」までに抑えられる。レーンでジャンプすると、それまで引いていたレーンはその場に残し、着いた先から新しく引く。妨害場がレーンに掛かると、ほかのレーンと同じくそこで寸断される。この艦が沈むか離脱すると、この艦が敷いたレーンはすべて消える
- **方舟**（ザイレンの旗艦）: 配置で「積まれる艦」に方舟を選んだ艦は、積まれた状態で始まる。積まれている艦は戦場にいない扱い（撃たない・撃たれない・探知されない）で、方舟と一緒に動く。方舟の探知距離の中に、陣営として動ける（反応時間を過ぎた）敵が入ると出し始め、「出す間隔」ごとに「1回に出す数」ずつ、方舟のそば（0.4〜0.8光秒）に出す。出た艦は配置で決めた行動で動く。方舟が沈むと積まれたままの艦も沈み、離脱すると一緒に離脱する。積める数を超えた分は積まれない
- **艦どうしの間隔**: 「艦どうしの最小間隔」（全体の設定。既定0.3光秒）より近い2隻は互いに押し離す。動けない艦（拠点・展開中の静穏場艦・延伸中のエルダ級・溜めている旗艦）は動かさない。1刻みに押せるのは、その艦が通常航行で進める距離まで
- **迎撃**: 迎撃をもつ艦は、迎撃の届く距離の中に来た誘導弾・無人機を、迎撃率で撃ち落とす。1回試みると迎撃の間隔だけ次を待つので、一度に大量に来ると追いつかない。近い艦から順に試みる
- **ジャンプ（任意座標）**: 目的地が「ジャンプを使う最短距離」より遠ければ跳ぶ（到着誤差あり）。着くとロックタイムが始まり、明けるまで跳べない。移動方式「自動」は、ロック明けを待って跳ぶのと通常航行のうち早く着くほうを選ぶ
- **リンク**: ノード艦の半径内の艦（1隻あたり上限あり）は、ロックタイムがリンク時の長さまで縮み、火力が上がる。ノード艦を失うと元に戻る
- **レーン**: レーン型の艦は、自陣営のレーンの近くにいれば、つながったレーン上のどこへでも一瞬で出られる。連続して跳べる（再ジャンプまでの間隔はロックタイム欄で決める）。エルダ級は敵の方へレーンを延ばす
- **妨害場**: 展開中の艦は動けない。完成すると範囲内では誰もジャンプできず、範囲内のレーンは寸断される。通常航行での出入りはできる
- **通信**: 情報共有が「通信艦がいるときだけ」の陣営は、通信艦がいない間（ジャンプ後の再同期中を含む）、各艦が自分の探知距離の中しか知らない
- **探知と反応**: 陣営として遠くの敵に動くのは、光の遅れ（距離の秒数）と反応時間が過ぎてから。射程の1.5倍以内の敵には即座に応戦する。「敵に位置を知られている」艦（拠点など）は、敵が最初から知っている
- **護衛と随伴**: 護衛は60光秒以内の要艦だけを守り、いなければ突撃と同じに動く。随伴は、いちばん近い味方の武装艦の塊（20光秒以内）に付いていく
- **救援**: 護衛の艦は、手が空いている（標的がなく、自分と守る艦のまわり60光秒以内に知っている敵の武装艦がいない）とき、攻められている味方の拠点（動かない艦。敵の武装艦がその射程の2倍+3光秒以内にいる）のうち、いちばん近いものを守りに行く。遠ければジャンプも使う。拠点の救援要請は、情報共有があればすぐ、なければ光の速さで届く（拠点までの距離の秒数だけ遅れる）。ノード艦などの動く要艦は対象にしない（守っている艦を置いて、離れた艦を追いかけてしまうため）
- **持ち場防衛の範囲**: 持ち場防衛の艦は、持ち場から「主砲の射程の2倍（最低10光秒）＋射程」の中の敵を標的にし、持ち場から「主砲の射程の2倍（最低10光秒）」までは標的へ寄る。貫く線を持つ艦は、標的にする範囲が貫く線の射程まで広がる（目標に着いたあと、少し離れて射程を保つ敵を前に動かなくなるのを防ぐ）
- **持ち場の切り替え**: 持ち場防衛の艦は、持ち場の15光秒以内に味方の拠点があればそれを守っているとみなし、その拠点が沈むと護衛に切り替える（その場で止まり続けないように）
- **撤退**: 艦の耐久が撤退ラインを下回るか、陣営の戦力が全軍撤退ラインを下回ると、離脱を図る。任意座標ジャンプの艦はロックが明けて妨害場の外にいれば跳んで離脱、レーン型はレーンに乗れれば離脱
- **勝敗**: 片方が全滅か全艦撤退で決着。制限時間に達したら、残存戦力（コスト × 耐久の割合。離脱した艦も含む）の割合で判定する

## 数値について

設定資料（`思考実験まとめ.md`）で決まっているのは、通常航行 0.05c、リンク時のロックタイム45分、通信艦の再同期15分、静穏場の展開15分・維持3時間、レーン敷設 1光分あたり40分、まで。耐久・火力・射程・回避・コストなどはすべて仮置き。S星系外縁の勝敗は設定資料の筋（A は人類勝ち、B はザイレン勝ち）に沿っている（テストで見ている）。

旧ビュワーの損耗は全体をまとめて減らすランチェスター型だったが、このツールは1隻ずつ撃ち合う形に変えた。

副兵装のシェル系統は設定資料にある（慣性弾。数万kmの交戦では回避され、近距離・拠点・密集目標向き）。ユーザーの案で、戦闘が始まる前に超遠距離から敵の群れへ撃ち込む先制の一撃として使う。拠点と砲撃艦に積む（ノード艦には積まない）。射程60光秒・弾速0.1c（着くまで最大10分。2026-10-16 にユーザーの指示で0.05cから倍にした）・爆発半径1光秒・その中の敵すべてにナーム級を一撃で沈める損害（600、拠点は3000。減衰なし）。弾数（砲撃艦6発・拠点12発）と間隔（5分）で絞っている。範囲に3隻以上入る群れのうち、コストの合計がいちばん大きい群れへ撃つ（貫く線と同じく、ユーザーの指示で数よりコストで選ぶようにした）。ウォードを素通りして船体に当たる。砲撃艦の名前と数値は仮置き。誘導弾・無人機・迎撃は設定資料にまだない兵器で、ミサイル艦・無人機母艦に積んである（2026-10-16 に正式な艦種にした）。

兵装の割り振り（2026-10-16 にユーザーと決めた）: ライン系統は全艦（設定「全艦が主力兵器として搭載」により、通信艦・静穏場艦も自衛用のごく弱いラインを持つ）。シェルは拠点と砲撃艦。迎撃はガード級・ノード艦・拠点など。ザイレンの兵装は片道の線だけで、ガルメス級は大型の幹線艦らしく片道の線を4門持つ（別々の敵を同時に撃つ）。ザイレンも誘導弾・無人機を迎撃できる（ガルメス級は中くらい、ナーム級は弱い）。ミサイル艦・無人機母艦は、正面衝突と大規模会戦（主力と増援）に入っている。

ザイレンの旗艦（オルドラ級）は、2026-10-16 にユーザーと決めたシミュレータだけの艦種（設定資料にはない）。動くハブ・攻城線砲・方舟の3つの役目を1隻にまとめ、大きさは拠点くらい（耐久6000・ウォード4000）。速さ0.02c、片道の線8門、迎撃はガルメス級並み。貫く線は溜め5分・射程30光秒・太さ0.3光秒・威力2000（ウォードで受けられる）。向きは線の上の敵のコストの合計がいちばん大きい向き（初めは「3隻以上並ぶ向きにだけ撃つ」だったが、距離を取って散らばる無人機母艦などを前に撃たずに待ち続けたので、ユーザーの指示でこうした）。行動は持ち場防衛で、貫く線を持つ艦は持ち場から貫く線の射程までの敵を標的にする（寄るのは持ち場から10光秒まで）。方舟はナーム級を最大40隻積み、30秒ごとに2隻ずつ出す。探知距離は貫く線の射程と同じ30光秒（積んだ艦を出し始める距離にも効く）。級名と数値は仮置き。いまは「巨大艦の試し」にだけ入っている（ほかのプリセットに艦種を足すと、狙い方の基準が変わって結果が動くため）。

## まだ入っていないもの

- 光の遅れは「見つけるまでの遅れ」だけに効く。見つけた後の位置は遅れなく追える
- ウォードの維持時間・乗員負荷、遮断艦（ドゥーレ級）、台帳艦（ペルタ級）、幹線艦が僚艦を運ぶ能力
- 陣営は2つまで。加速・慣性・衝突はない
- 副兵装は1艦種に1つまで。主砲・副兵装とも、無人機を標的にはできない（無人機を落とせるのは迎撃だけ）
- シェルの見越しは、撃った時点の敵の向きと速さだけを使う（敵の目標地点などは読まない）。撃たれる側がシェルに気づいて避けることはない

## ファイル

- `index.html`: 画面と見た目
- `engine.js`: 計算エンジン。DOM に依存しないので Node でも動く
- `presets.js`: 艦種の初期値とプリセットのシナリオ
- `ui.js`: 地図の描画と操作、編集画面、再生、結果
- `viewer3d.html`・`viewer3d.js`: 3Dビューア。`viewer3d-models.js`: 艦の既定モデルと GLB への差し替え。`viewer3d-audio.js`: 効果音（Web Audio で合成）
- `models/`: 差し替え用の GLB と `models.json`、`tools/pack-models.js` で作る `models.js`
- `tools/pack-models.js`: `models/` の GLB を `models.js` にまとめる（ファイルを直接開いたビューアでも読めるように）
- `tools/battle.js`: 戦闘を回して勝率と損害をまとめる。`tools/sweep.js`: 値を振って比べる。`tools/lib.js`: その共通部品。`tools/export-presets.js`: プリセットを `scenarios/` に書き出す
- `scenarios/`: プリセットのシナリオ JSON
- `test/run.js`: エンジンのテスト。`node test/run.js` で実行する
- `CLAUDE.md`: Claude Code 向けの作業メモ。`操作方法.md`: 画面の操作。`シナリオ形式.md`: JSON の形式
